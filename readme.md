Chess Game

This project was an exercise given by my instructor.

Description

A browser-based chess game with full rule validation (checks, checkmate, castling, en passant, and pawn promotion), move history, captured piece tracking, and a computer opponent with two difficulty levels, as well as a two-player mode.

How to run

Open chess.html in any modern web browser. No installation or server required.

Features


Full legal move validation
Two-player mode
Computer opponent (easy: random moves, medium: minimax search)
Move history log
Captured pieces display
Undo move / new game controls
